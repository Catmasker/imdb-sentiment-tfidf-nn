# IMDB Sentiment Analysis with GloVe + Neural Network

A complete ML project with automated CI/CD pipeline that trains a sentiment analysis model and deploys it to Hugging Face Hub.

## Architecture

```
Input Text → Clean & Tokenize → GloVe Embedding Lookup → Mean+Max Pooling (100-dim)
    → MLP (100→256→128→64→1) + BatchNorm → Sigmoid → Positive/Negative
```

## Dataset

- **imdb_balanced_10k.csv** — 10,000 balanced IMDB movie reviews
- **tiny_glove.json** — 4,993 words with 50-dimensional GloVe vectors

## Project Structure

```
├── data/                  # Datasets (csv + glove embeddings)
├── model/                 # Trained model artifacts (auto-generated by CI)
├── train.py               # Training script
├── predict.py             # Inference script
├── requirements.txt       # Python dependencies
├── README.md
└── .github/workflows/
    └── train-and-upload.yml   # GitHub Actions CI/CD
```

## Usage

### Train
```bash
python train.py
```

### Predict
```bash
python predict.py "This movie was fantastic!"
```

## CI/CD

On every push to `main`/`master`, GitHub Actions automatically:
1. Installs dependencies
2. Runs `train.py`
3. Uploads model artifacts to Hugging Face Hub
