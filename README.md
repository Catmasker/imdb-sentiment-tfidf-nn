# IMDB Sentiment Analysis with TF-IDF + Neural Network

[![Train and Upload to Hugging Face](https://github.com/Catmasker/imdb-sentiment-nn/actions/workflows/train-and-upload.yml/badge.svg)](https://github.com/Catmasker/imdb-sentiment-nn/actions/workflows/train-and-upload.yml)

A complete ML project with automated CI/CD pipeline that trains a sentiment analysis model and deploys it to Hugging Face Hub.

## How It Works

```
Input Text → Clean → TF-IDF (25000 unigrams+bigrams) → Linear NN → Positive/Negative
```

The model uses **TF-IDF features** (term frequency-inverse document frequency) instead of simple word averaging. This gives more weight to sentiment-bearing words ("amazing", "terrible") and less to common words ("the", "a"). A small neural network (25000→16→1) with strong L2 regularization prevents overfitting.

## Dataset

- **imdb_balanced_10k.csv** — 10,000 balanced IMDB movie reviews (5,000 positive, 5,000 negative)
- **tiny_glove.json** — 4,993 words with 50-dimensional GloVe vectors (used in earlier experiments)

## Model Development History

| Approach | Accuracy | Issue |
|----------|----------|-------|
| GloVe mean+max pooling | 73.05% | Too much information loss |
| TF-IDF (5000) + deep MLP | 84.50% | Severe overfitting |
| TF-IDF (3000) + medium MLP | 85.95% | Still overfitting |
| BiLSTM + GloVe | 82.25% | Low vocabulary coverage |
| **TF-IDF (25000) + linear NN + strong L2** | **90.25%** | **Best balance** |

## CI/CD

On every push to `main`/`master`, GitHub Actions automatically:
1. Installs dependencies
2. Runs `train.py`
3. Uploads model artifacts to Hugging Face Hub

### Setup Instructions

1. Create a Hugging Face account at https://huggingface.co
2. Generate a token at https://huggingface.co/settings/tokens
3. Add the token as a repository secret `HF_TOKEN` in your GitHub repository settings
